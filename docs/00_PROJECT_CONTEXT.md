# Mohammed Attallah — Website Project Context

## 1. Project Overview

This project is the design and development of a premium personal-brand website for **Mohammed Attallah**, an Automation Technical Leader at Schneider Electric.

The website is intended to become the central digital hub for Mohammed's professional identity, expertise, education activity, and future consulting opportunities.

This is not intended to be a simple CV website or a standalone course website.

The core concept is:

**Mohammed Attallah = the personal brand**

with two principal professional pillars:

1. **Technical Consulting & Advisory**
2. **Easy Automation Academy**

The website should make Mohammed's personal expertise the central focus, while presenting education as one important part of his broader professional identity.

---

## 2. Strategic Goal

The primary goal is to create a website that immediately communicates:

- technical authority
- real-world automation experience
- leadership
- credibility
- practical expertise
- education
- professional maturity
- precision
- premium positioning

The desired perception is:

> **"This is not just a website for my course — this is a serious premium platform representing me as an automation expert."**

The website should feel like a professional digital platform built around an established technical expert, rather than a template-based portfolio or an online course storefront.

---

## 3. Brand Architecture

### Master Brand

**Mohammed Attallah**

This is the central identity.

The website should position Mohammed primarily as:

- Automation Expert
- Technical Leader
- Educator

### Professional Pillar

**Technical Consulting & Advisory**

This represents a potential consulting/advisory dimension around Mohammed's technical expertise.

Important: consulting scope and availability have not yet been fully confirmed.

Therefore, the website should introduce this area carefully and honestly.

Preferred language includes:

- Technical Consulting & Advisory
- Discuss a Technical Challenge
- Start a Conversation
- Scope & availability to be confirmed

Do not present consulting as a fully established commercial business unless Mohammed confirms this.

### Education Pillar

**Easy Automation Academy**

This is Mohammed's education division / sub-brand.

The Academy should benefit from Mohammed's personal authority, rather than becoming a separate brand that overshadows him.

The preferred hierarchy is:

**Mohammed Attallah**
→ **Easy Automation Academy**
→ Courses
→ Course Detail
→ External Enrollment

External platforms such as Payhip or Udemy are considered transaction/course-delivery endpoints, not the primary brand.

## 12. Visual Direction

The approved visual direction is:

# The Engineering Journal

The intended character is:

- precision
- editorial confidence
- technical maturity
- restraint
- calm authority

The interface should use:

- cool-neutral light backgrounds
- deep graphite / ink text
- one controlled copper / amber accent
- rectilinear grid
- thin hairline rules
- generous spacing
- minimal border radius
- almost no shadows
- restrained motion
- real project photography
- subtle technical diagram motifs

The Project Proof section may use a darker, more dramatic treatment.

The whole website should NOT become a:

- SCADA dashboard
- cybersecurity dashboard
- futuristic AI interface
- neon technology website
- generic SaaS landing page

## 21. Important Brand Protection

Mohammed's employment at Schneider Electric is an important credibility signal.

However, the personal website must not imply that Schneider Electric:

- endorses the website
- sponsors the website
- partners with Easy Automation Academy
- endorses the courses
- is a consulting client
- operates or owns the personal brand

The website should communicate Mohammed's employment fact accurately and separately from his personal brand activities.
