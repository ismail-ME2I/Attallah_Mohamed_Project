## 3. The Brand Architecture

```
MOHAMMED ATTALLAH (personal brand / central hub)
        |
   ------------------------
   |                      |
CONSULTING            EDUCATION → Easy Automation Academy
   |                      |
Services              Courses
   |                      |
Book Consultation     External platforms (Payhip, Udemy, etc.)
```

Mohammed's personal brand is the top-level identity. Easy Automation Academy is a sub-brand under Education. External platforms are transaction/delivery layers only — they must never become the primary identity the visitor associates with.

## 4. Role of Easy Automation Academy

A dedicated, branded section within the Mohammed Attallah site — not a copy of the existing Payhip page. It should communicate educational philosophy, let visitors browse courses, and hand off to external platforms only at the point of enrollment. It is the **discovery, authority, and conversion layer**; it is not the transaction layer.

## 5. Role of External Platforms (Payhip / Udemy / etc.)

Pure **transaction + course-delivery** endpoints. The user journey is: Mohammed's site → Easy Automation Academy → Course Detail → external platform for actual enrollment/payment. They should never be framed as the destination brand.

## 6. Current Phase 1 Objective

Produce a **"WOW demo"**: strong visual direction, strong IA, clear dual positioning (Consulting + Academy), a believable course-discovery flow, and a demo-ready UI/UX — using only currently confirmed information, with elegant placeholders where content is genuinely missing. Success is measured by whether Mohammed feels represented at a higher level and wants to proceed, not by feature completeness.
